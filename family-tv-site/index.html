Press “Set up” to connect your Google Drive folder.

Set up your station

Point Family TV at the Drive folder that holds your family movies. It plays everything in it, including subfolders, and starts over when it reaches the end.

The folder needs sharing set to “Anyone with the link can view.”
Stored only in this browser. Free to create, steps below.
How to get an API key (about 3 minutes)
  1. Open console.cloud.google.com and create a project.
  2. Go to APIs & Services → Library, search “Google Drive API,” and click Enable.
  3. Go to APIs & Services → Credentials → Create credentials → API key.
  4. Optional but smart: restrict the key to the Google Drive API.
  5. In Drive, right-click your movies folder → Share → General access → Anyone with the link.
